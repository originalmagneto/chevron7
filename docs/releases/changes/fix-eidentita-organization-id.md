- **Nastavenie podpisu cez eIdentitu zodpovedá novému portálu Autogram.** Portál Autogram presunul kľúč pre integrácie z profilu používateľa do nastavení organizácie. Chevron7 preto v Nastaveniach (Podpisovanie mobilom, eIdentita) žiada ID organizácie namiesto ID používateľa a popisuje, kde ho nájdete: na portáli otvorte Nastavenia, do poľa „Verejný kľúč API tokenu“ vložte kľúč z Chevron7 a do Chevron7 prepíšte číslo z vety „V tokene použite sub = …“. Ak portál píše, že API prístup nie je zapnutý, požiadajte správcu portálu o jeho zapnutie. Ak ste predtým zadali ID používateľa, nahraďte ho ID organizácie.
