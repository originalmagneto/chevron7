- **Podpisovanie zo Safari funguje hneď po aktualizácii.** Po automatickej aktualizácii Chevron7 ostal na pozadí bežať starý pomocník prepojenia so Safari, ktorý rozšírenie odmietalo, a stránka (napríklad nove.slovensko.sk) potom iba ukazovala „Čakajte, prosím, práve prebieha spúšťanie podpisovej aplikácie“, kým ste nereštartovali Mac. Chevron7 teraz starého pomocníka pri spustení sám ukončí a macOS spustí nového z aktuálnej verzie.
